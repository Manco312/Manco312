## 🚀 Featured Projects

### 🤖 Inventech Analytics
A **Django web application** for managing food inventory with support for **AI-driven suggestions** and **data analytics**.  
It helps users make better decisions based on sales behavior, product expiration dates, and inventory trends.

### 📄 JobAligner
A **Django-based platform** that helps job candidates tailor their CVs to specific job vacancies.  
It uses **AI** to generate **ATS-friendly resumes** and includes **PDF export** functionality.

### 🔢 ShadowSolver
A **Django application** focused on **numerical analysis methods**, designed as an accessible tool for learning and experimentation.  
It is deployed and available for public use.
